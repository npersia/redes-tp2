## Para ejecutar el codigo

### Comando para ejecutar el controlador, desde la carpeta base de pox:
    python3 pox/pox.py log.level --DEBUG protorouter

Esto se agregar en la carpeta del repo de pox, pox/ext para vincular nuestra implementacion a pox:

ln -s /ruta/a/tu/repo/protorouter.py protorouter.py

El settings es para poder importar elementos de pox a nuestro repo
